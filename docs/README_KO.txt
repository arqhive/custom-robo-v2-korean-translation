커스텀 로보 V2 (N64) 한글 패치 {VERSION}
제작: arqhive

「カスタムロボV2」(N64, 일본판) 비공식 한국어 팬 패치입니다.
본편 대사, 선택지, 메뉴, 파츠 설명, 도움말·조작 안내, 스테이지 설명, 저장 안내,
타이틀 로고와 메뉴·승리 표시·간판 그림 속 글자를 한글로 바꿉니다.


[준비물]

- 일본판 「カスタムロボV2」 롬 파일(z64, 빅 엔디언).
  .v64·.n64처럼 바이트 순서가 다른 파일은 먼저 z64로 바꿔야 합니다.
- xdelta 패치를 적용하는 프로그램(Delta Patcher, xdelta UI 등).


[적용 방법]

1. 패치 프로그램에서 원본 롬과 NCZJ_KPatch_{VERSION}.xdelta 를 고릅니다.
2. 적용하면 한글판 롬이 만들어집니다.
3. 만들어진 롬의 해시가 아래 「패치 후」와 같은지 확인합니다.


[해시]

  패치 전(원본 롬)
    크기    16,777,216 바이트
    CRC32   C8201454
    MD5     115118dd5e0f02d82ba1bf070a7b78f1
    SHA-256 60acf8dc7361f155ec8c987f75c6988ca1b0ccd36baefaffd67c24af6d21ace1

  패치 후({VERSION})
    크기    16,777,216 바이트
    CRC32   {RESULT_CRC32}
    MD5     {RESULT_MD5}
    SHA-256 {RESULT_SHA256}


[실행 환경]

- 확인함: RMG(Rosalie's Mupen GUI), Wii U 버추얼 콘솔(UWUVCI 주입, 베이스 Mario Golf US).
- 세이브는 16K EEPROM입니다. 에뮬레이터가 패치한 롬을 모르는 롬으로 보고 세이브 종류를
  4K로 잡으면 저장이 깨질 수 있습니다. 그럴 때는 에뮬레이터 설정에서 16K EEPROM으로 맞춰 주세요.


[참고]

- 주인공 이름은 한글로 입력할 수 있습니다. 이름 입력 첫 페이지에서 자음·모음을 차례로 고르면
  글자가 조합됩니다(최대 6글자).
- 이름 뒤 조사(을/를, 이/가 등)는 이름 끝 글자의 받침에 맞춰 자동으로 바뀝니다.
- 원래 영어로 나오는 글자는 영어로 두었습니다.
