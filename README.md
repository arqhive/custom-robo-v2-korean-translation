# 커스텀 로보 V2 (N64) 한글 패치

*Custom Robo V2* (닌텐도 64, 일본판 `NCZJ`) 비공식 한국어 팬 패치입니다.
일본판(『カスタムロボV2』) 원문을 기준으로 번역했고, 1편 한글 패치와 용어·말투를 이어 맞췄습니다.

**제작: arqhive** · **최신 버전: [v1.0f](../../releases/tag/v1.0f)**

**소개 페이지: [arqhive 한글 패치 아카이브](https://arqhive.vercel.app/korean-translation/custom-robo-v2)**

- 본편 대사, 선택지, 메뉴, 파츠 설명, 도움말·조작 안내, 스테이지 설명, 저장 안내를 한글화했습니다.
- 타이틀 로고와 메뉴·승리 표시·조작 안내·간판 그림 속 글자를 한글화했습니다.
- 주인공 이름을 한글로 입력할 수 있습니다. 이름 뒤 조사(을/를, 이/가 등)는 이름 끝 글자의 받침에 맞춰 자동으로 바뀝니다.
- 원작에서도 영어인 문구는 영어 그대로 두었습니다.
- 배포본은 원본 롬에 적용하는 **xdelta 패치**입니다. 롬 크기(16MB)는 그대로이며 확장팩은 필요 없습니다.

> 이 저장소에는 **게임 데이터(롬, 추출한 원문 대사, 원본 그래픽, 스크린샷)가 들어 있지 않습니다.**
> 패치를 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 롬 파일(z64, 빅 엔디언). 북미판·유럽판은 없는 게임입니다.

| 항목 | 패치 전(원본) | 패치 후(v1.0f) | 패치 후(v1.0f EEPROM16K판) |
|---|---|---|---|
| 크기 | 16,777,216바이트 | 16,777,216바이트 | 16,777,216바이트 |
| CRC32 | `C8201454` | `5A13917F` | `C4020976` |
| MD5 | `115118dd5e0f02d82ba1bf070a7b78f1` | `1f5415c7dcd2010be9bcc2d89c502f94` | `7edadcf7051c288b7768bf3ec47c155c` |
| SHA-256 | `60acf8dc7361f155ec8c987f75c6988ca1b0ccd36baefaffd67c24af6d21ace1` | `13fd9e0be063d3f82d5cb26dc9fdddad60b9bb2ffa4a6865bf2e189bec36ea69` | `42f22d46d962866c6e8af6230fc89ab7c8d77cb131eeaba845918ca4872dc7da` |

`.v64`·`.n64`처럼 바이트 순서가 다른 파일은 먼저 z64로 바꿔야 합니다.

- xdelta 패치를 적용하는 프로그램(Delta Patcher, xdelta UI 등).

### 적용 방법

1. [릴리즈 페이지](../../releases/latest)에서 `NCZJ_KPatch_v<버전>.zip`을 받아 압축을 풉니다.
2. 패치 프로그램에서 원본 롬과 xdelta 파일 하나를 고르고 적용합니다.
   - `NCZJ_KPatch_v<버전>.xdelta`: 기본판. RMG, Wii U 버추얼 콘솔(UWUVCI)에서 쓰세요.
   - `NCZJ_KPatch_v<버전>_EEPROM16K.xdelta`: 안드로이드 에뮬레이터(M64Plus FZ, RetroArch, Lemuroid 등)처럼 세이브 종류를 직접 고를 수 없는 에뮬레이터용입니다. 롬 헤더에 16K EEPROM 표시를 넣어 mupen64plus 계열 에뮬레이터가 설정 없이도 세이브를 16K로 잡게 했습니다. 내용(대사·그림)은 기본판과 같습니다.
3. 만들어진 롬의 해시가 위 표의 「패치 후」와 같은지 확인하고 실행합니다.

### 실행 환경

- **확인함**: RMG(Rosalie's Mupen GUI), Wii U 버추얼 콘솔(UWUVCI 주입, 베이스 Mario Golf US).
- **EEPROM16K판**: RMG에서 별도 설정 없이 16K 세이브로 잡히고 진행되는 것을 확인했습니다. 안드로이드 기기에서는 직접 확인하지 못했습니다.

### 알려진 문제

- 파츠 이름·설명이 나오는 창이 너무 좁아서, 일부 파츠 이름은 띄어쓰기를 생략했고 파츠 설명은 문장 끝 마침표를 생략했습니다.
- 이 게임의 세이브는 16K EEPROM입니다. 에뮬레이터는 롬 해시로 세이브 종류를 정하는데, 패치한 롬은 해시가 달라 에뮬레이터가 모르는 롬으로 보고 4K로 잡을 수 있습니다. 이때는 저장이 깨지거나 새 게임으로 시나리오에 들어갈 때 게임이 멈출 수 있으니, 에뮬레이터 설정에서 세이브 종류를 16K EEPROM으로 직접 맞춰 주세요. 설정할 수 없는 에뮬레이터(안드로이드 등)는 EEPROM16K판 패치를 쓰세요. Wii U 버추얼 콘솔(UWUVCI)은 기본 INI가 16K EEPROM이라 기본판을 그대로 쓰면 됩니다.

## 개발자용

- 번역문: [`work/translation/out/`](work/translation/out)에 ID별 한국어 번역문만 들어 있습니다. `$R`은 줄바꿈, `$P`는 쪽 넘김, `$W`는 입력 대기, `$A00`은 주인공 이름, `$B00`은 가짜 이름 자리라 그대로 둡니다. `{을/를}`·`{이/가}`·`{은/는}`·`{과/와}`·`{아/야}`·`{이}`·`{으}`·`{에/예}`는 이름 뒤 조사 표기입니다.
- 도구: [`tools/`](tools)에 추출·글꼴·빌드·검사·배포 도구 소스가 있습니다(Python 3.13, NumPy, Pillow, keystone-engine, unicorn).
- 일본어 원문 추출본, 그림 작업 파일, 작업 상태 기록은 게임 데이터이거나 작업용이라 넣지 않았습니다. 그래서 이 저장소만으로는 바로 빌드되지 않고, 원본 롬에서 추출부터 다시 해야 합니다.
